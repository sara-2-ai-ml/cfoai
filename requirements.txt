# --- GRAPH RAG / HYBRID CHAT NOTES -------------------------------------------

# Upload pipeline:
#   PDF/Excel → ChromaDB (vector) + Neo4j (entity graph via Claude extraction)

# Chat pipeline (hybrid retrieval):
#   Question → Vector RAG (Chroma) + Graph RAG (Neo4j) in parallel
#           → RRF merge → Claude → answer + citations

# Graceful fallback:
#   Neo4j down   → chat uses vector RAG only
#   Chroma down  → chat uses graph RAG only
#   Both down    → error RETRIEVAL_UNAVAILABLE
